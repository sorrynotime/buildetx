# Open Radio Builder 使用说明

> 本文由 AI 助手「小构」代笔，主人尚未审核，您们将就着看。

一个 Windows 上的小工具，用来给遥控器（EdgeTX）和高频头 / 接收机（ExpressLRS）编译固件。全部操作都在界面上点按钮完成，不需要敲命令。

## 第一次使用：先把工具装好

只有编译「EdgeTX 固件」才需要下面这套工具；编「ExpressLRS」只要电脑上有 Python，其它由软件自己准备。

工具都放在工程目录的 `attachment` 文件夹里，按下面的顺序装一次即可：

| 顺序 | 用什么 | 怎么装 |
| --- | --- | --- |
| 1 | `VisualStudioSetup.exe` | 双击安装，组件照 `vs2022.png` 勾选（要勾的几项列在下面） |
| 2 | `cmake-4.4.2-windows-x86_64.msi` | 双击，一路下一步；安装时把「添加到 PATH」选上 |
| 3 | `ninja-win.zip` | 解压，把里面的 `ninja.exe` 放到 CMake 的安装文件夹（和 `cmake.exe` 放一起） |
| 4 | `arm-gnu.txt` | 里面写明了版本和下载地址，照着下载 14.2.Rel1 的安装包并装上；这个文件比较大，没放进附件 |
| 5 | Git、Python | 电脑没装就先装好；Python 安装时勾选「Add Python to PATH」 |

`vs2022.png` 里要勾的几项：

- MSVC v143 - VS 2022 C++ x64/x86 生成工具
- 适用于 Windows 的 C++ Clang 编译器
- 适用于 x64/x86 的 MSVC 生成工具
- 用于 Windows 的 C++ CMake 工具
- Windows 11 SDK

装完如果软件已经开着，关掉重新打开，点 `检查环境`：日志里没有「缺失」就可以往下走；哪一项缺了，就回到上表对应那一步补装。工具只需要装一次，换电脑或重装系统才要重来。

## 打开软件

1. 双击 `OpenRadioBuilder.exe`。
2. 顶部「源码目录」一般会自动填好；如果空着或不对，点右边的「浏览」，选到你放源码的文件夹。
3. 选过一次就会记住，下次打开自动填。源码文件夹请保持下载时的原样，不要改动里面的目录结构。

> 顶部两个大按钮决定你要编哪种固件：`EdgeTX 固件` 和 `ExpressLRS`。

## 界面看哪里

- 上半部分：选型号、勾功能。
- 下半部分「构建操作」：一排按钮、状态栏、进度条和日志。
- 编译时看状态栏和日志就行；出现「编译成功了，固件已生成」就完成了。

## 一、编译遥控器固件（EdgeTX）

1. 点 `EdgeTX 固件`。
2. 确认「源码目录」。第二个输入框一般保持默认。
3. 点 `检查环境`，看日志里有没有「缺失」。第一次使用请先按最前面「先把工具装好」装完；缺 Python 相关的就点 `安装 Python 依赖`，其它缺什么按提示装好，再点一次 `检查环境`。
4. 点 `获取发射机型号`，依次选：厂商、型号、类型、语言、手型设置。「目录」不用管。
5. 按自己的遥控器勾选：常用功能（直升机、飞行模式、曲线、全局变量、Lua 等）、协议支持、模块支持、硬件配置（FS 霍尔摇杆、蓝牙、内置 GPS、摇杆死区、摇杆类型）。灰掉的项表示该型号不支持；如果同时开了会冲突的硬件，软件会弹窗提醒，关掉其中一个即可。
6. 点 `配置 CMake`，等状态栏提示完成。
7. 点 `编译固件`，等进度走完、日志出现成功提示。
8. 固件在源码文件夹的 `build\<型号>\arm-none-eabi\` 里，文件名 `firmware.bin`。

改过勾选项后，把 `build` 文件夹里旧的内容清掉，再重新点第 6、7 步，否则可能还是旧固件。

---

## 二、编译高频头 / 接收机固件（ExpressLRS）

1. 点 `ExpressLRS`，确认「源码目录」。
2. 点 `检查环境`；如果按钮显示 `安装 PlatformIO`，点一次等它装完。第一次会联网下载工具，耐心等。想提前下载可以点 `预下载平台包`。
3. 点 `读取编译目标 / 型号`。
4. 依次选：设备类型（TX 是发射端 / 高频头，RX 是接收机）、厂商、型号、编译目标。选好型号后，下面一行会显示这个型号的固件、上传方式等信息。
   - 厂商选 `（手动选择目标）` 时，跳过厂商和型号，直接按 TX / RX 挑编译目标。
   - 显示「当前源码无对应编译目标」说明这型号太老，换个型号或用手动模式。
5. 填 `user_defines 常用配置`：频段、绑定短语、首次连接锁定，点 `保存 user_defines`。也可以点 `打开 user_defines.txt` 自己改。
6. 需要改设备参数时，点 `查看硬件配置`，双击表格里的行改数值，还能填设备名、勾选「RX 当 TX」，然后保存。以后每次编译会自动用上这份配置，原来的文件不会被改动。
7. 点 `编译固件`，等状态栏显示完成。
8. 点 `打开产物目录` 拿固件。如果第 6 步存过自定义配置，要刷的是 `output` 文件夹里那个 `*.custom.bin`，界面上的「产物」也会指向它。

厂商 / 型号下拉是空的：多半是源码目录没选对，重新点「浏览」选到源码文件夹，再点一次 `读取编译目标 / 型号`。

## 按钮速查

| 按钮 | 什么时候点 |
| --- | --- |
| 检查环境 | 第一次装完工具、换电脑、编译报错时 |
| 安装 Python 依赖 / 安装 PlatformIO | 环境检查提示缺东西时 |
| 预下载平台包 | ExpressLRS 第一次编译前，想先把工具下载好 |
| 获取发射机型号 / 读取编译目标 / 型号 | 刚打开软件、换了源码、型号列表为空时 |
| 配置 CMake | EdgeTX：选好型号和选项后、改过选项后 |
| 编译固件 | 出固件 |
| 路径设置 | 想改固件副本、配置副本放在哪 |
| 打开产物目录 | 找刚编出来的固件 |
| 查看硬件配置 | 改设备参数、设备名、RX 当 TX |
| 清除日志 | 日志太长想清空 |

## 遇到问题

- **检查环境里一堆「缺失」**：第一次用没装工具，按最前面「先把工具装好」装一遍，再点 `检查环境`。
- **第一次编译很久**：正在下载工具，等就好，别关窗口。
- **提示缺这个缺那个**：按日志提示装好，再点 `检查环境`；Python 相关的直接点 `安装 Python 依赖`。
- **提示硬件冲突**：FS 霍尔摇杆和蓝牙不能同时开，关掉一个。
- **改了选项，固件没变化**：清掉 `build` 文件夹旧内容，重新 `配置 CMake` 再 `编译固件`。
- **编译失败**：看下方日志最后几行，按提示补齐后再点一次 `编译固件`。
- **找不到固件**：EdgeTX 看源码文件夹里 `build\<型号>\arm-none-eabi\firmware.bin`；ExpressLRS 直接点 `打开产物目录`。
- **刷机前**：再核对一遍厂商、型号、语言和功能勾选，别刷错板子。

## 记住三件事

1. 工具装一次就行，源码目录选一次就会记住，下次打开自动填。
2. 改过选项要重新「配置 CMake」再编译。
3. 编译成功后，按上面的位置去拿固件文件。
